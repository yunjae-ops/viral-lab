# HOOK_CODES.md — Hook Code A~M 정의 (확정)

이 문서에 있는 정의는 **확정판**이며, `docs/DATA_CONTRACT.md`의 `diagnostic.hookCode` enum과 정확히 일치한다.
정의를 바꾸려면 `promptVersion`을 반드시 올린다.

## Enum

```
A | B | C | D | E | F | G | H | I | J | K | L | M
```

`OTHER`는 이 축에서는 허용하지 않는다. A~M 13개 중 하나로 반드시 분류한다.
분류가 어려운 경우 AI는 가장 근접한 코드 하나를 고르고, `hookCodeReason`에 그 근거를 남긴다.

## 정의

| 코드 | 이름 | 정의 |
|---|---|---|
| **A** | 직접 추천형 | 화자가 겪고 → 발견 → 추천 |
| **B** | 위장된 자랑/반전 | 손해나 부정적 사건 속에서 만족 발견 |
| **C** | 장애물 나열형 | 여러 실패 시도 → 마지막 해결 |
| **D** | 안티추천 뒤집기 | 다른 것들 불신/비추천 → 하나만 예외 |
| **E** | 장르클리셰 반전 | 태몽·사주 등 반전 구조 장르 활용 |
| **F** | 순수 리스트형 | 행동 나열 / 결과 숫자 훅 |
| **G** | 발견형 | 결핍 없이 우연한 발견 |
| **H** | 권위+허무개그 | 전문가 권위 + 이렇게 간단한 걸 |
| **I** | 부담-면제리스트 | 과도한 기준/부담 나열 → 최소 솔루션 |
| **J** | 선언문형 명령 리스트 | 강한 선언 + 균질한 행동 리스트 |
| **K** | 상황별 제품 매칭 리스트 | 여러 상황/고민에 각 솔루션 매칭 |
| **L** | 시크한 관찰자형 | 절박함 없는 무심/훈수 톤 |
| **M** | 나이듦 수용/철듦형 | 예전엔 몰랐지만 이제 이해한다는 성숙 서사 |
